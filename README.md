# ashen-oath
## Play

https://devworks12.github.io/ashen-oath/

A browser 3D boss fight for phones in landscape. Built with three.js (loaded from jsDelivr).

Credits: floor, wall, metal and rock textures, boulder model and night HDRI from Poly Haven (CC0). Fonts: Cinzel and Cormorant Garamond (SIL Open Font License, see `fonts/`). Everything else is generated in code or modelled for this game.
